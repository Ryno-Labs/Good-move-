# Good Move — PWA

A small offline-first daily motivation app for managing waiting on others.

## Put it on GitHub Pages

1. Create a new **public** GitHub repository named `good-move`.
2. Upload **all files and the `icons` folder** from this package to the root of the repository. Commit to `main`.
3. Open **Settings → Pages**, then set **Build and deployment → Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Once Pages finishes publishing, open `https://YOUR-USERNAME.github.io/good-move/`.
5. On iPhone, open the site in Safari, tap Share → **Add to Home Screen**.

## Features

- Four action buttons: clear up, help someone, move it forward, improve a process.
- Daily points, daily good-move count, day streak.
- Daily rotating mini mission (bonus points).
- Waiting-on tracker, ready-to-send follow-up text, and close-out.
- Private data stored only in this browser/device (`localStorage`), not synced to other devices.
- Works offline after first successful load.

No build, Node, Astro, npm, server, or API needed.
